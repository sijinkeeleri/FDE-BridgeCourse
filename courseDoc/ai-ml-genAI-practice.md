# Practice Exercise: Applying AI Concepts

### 1. Automated Task Prioritization

Technology: Supervised Learning

Justification: This feature should use supervised learning because it is trained on a large dataset of past tasks that already have correct priority labels. The model learns to map task features to known outputs such as High, Medium, and Low.

### 2. User Persona Discovery

Technology: Unsupervised Learning

Justification: This feature should use unsupervised learning because the system must discover natural patterns or clusters in user behavior without predefined labels. It is suitable for identifying hidden user groups such as Power Planners or Casual Communicators.

### 3. "Smart Summary" Assistant

Technology: Generative AI / LLM

Justification: This feature should use generative AI or an LLM because it needs to create a new, human-like summary from a long discussion thread. The goal is not just classification or clustering, but producing original text that captures key points and action items.

### 4. Adaptive Onboarding Tutorial

Technology: Reinforcement Learning

Justification: This feature should use reinforcement learning because the tutorial system learns through trial and error by interacting with users and receiving feedback. It improves its strategy over time by rewarding successful actions and adjusting when users struggle or make errors.
